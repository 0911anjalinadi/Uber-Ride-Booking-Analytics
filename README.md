🚕 Uber Ride Booking Analytics & Performance Dashboard

📌 Overview

The Uber Ride Booking Analytics & Performance Dashboard is a
data analytics and web-based visualization project designed to
analyze ride booking performance and generate meaningful
business insights from Uber ride booking data.

The project combines Microsoft Excel, Python and modern web
technologies to transform raw booking data into an interactive
analytics dashboard.

🎯 Objectives

- Analyze overall ride booking performance
- Understand booking status and cancellation patterns
- Compare vehicle-wise bookings and revenue
- Analyze payment methods
- Identify top pickup locations
- Analyze driver and customer ratings
- Present insights through an interactive dashboard

🛠️ Technologies Used
- Microsoft Excel
- Python
- Pandas
- NumPy
- Flask
- React.js
- Recharts
- Git & GitHub

 📊 Excel Analysis

The initial analysis was performed in Microsoft Excel using:
- Data cleaning
- Excel Tables
- Pivot Tables
- KPI calculations
- Interactive charts
- Dashboard creation

🐍 Python Analysis

Python was used for data processing and analysis using:
- Pandas
- NumPy
- Matplotlib

💻 Web Dashboard
The analyzed data is presented through a React-based web dashboard.

The dashboard provides:
- KPI cards
- Booking status analysis
- Vehicle booking analysis
- Revenue analysis
- Monthly booking trends
- Pickup location analysis
- Payment method analysis
- Vehicle ratings
